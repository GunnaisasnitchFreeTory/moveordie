# Fate Beams

A fast-paced survival game built with Rojo.

## Quick Start

```bash
# Build the place file
rojo build -o "FateBeams.rbxlx"

# Or serve for live sync
rojo serve
```

Then open in Roblox Studio and connect via the Rojo plugin.

## Project Structure

```
src/
  client/     → StarterPlayerScripts
  server/     → ServerScriptService
  shared/     → ReplicatedStorage
docs/         → Project documentation
```
